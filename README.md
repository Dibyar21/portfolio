## 📌 About The Project

**DJ.dev** is my personal developer portfolio website designed to showcase my technical skills, projects, internship experience, certifications, resume and professional journey.

The website focuses on a modern developer-oriented interface with a dark theme, cyan/blue visual elements, glassmorphism effects and smooth animations.

It is fully responsive and optimized for desktop, tablet and mobile devices.
